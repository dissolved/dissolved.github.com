# codedissolved.com source

Generated by [Jekyll](https://jekyllrb.com/)

Install the Ruby version in `.tool-versions` using `asdf`, then install the
locked dependencies and preview the site:

```sh
asdf install
bundle install
bundle exec jekyll serve
```

Build and check the site:

```sh
JEKYLL_ENV=production bundle exec jekyll build
python3 scripts/check_links.py _site
```

The link checker uses Python 3's standard library and checks internal links,
fragments, images, and local assets. It does not check external sites.

Use `bundle update` to refresh dependencies and commit `Gemfile.lock` with any
dependency changes.

Analytics use hosted GoatCounter at `https://dissolved.goatcounter.com`.
The `goatcounter` setting in `_config.yml` is the public counting endpoint; leave
it blank to disable analytics. The script is included only when
`JEKYLL_ENV=production`, and automatic tracking is disabled on hostnames other than
the production hostname in `url`. Normal local previews do not load the tracker.
After deployment, verify a pageview in the GoatCounter dashboard using a browser
that allows its script. Local builds do not verify live data collection.
Automated browsers are identified as bots; HTTP 200 on a counting request does
not prove a normal visit was recorded.

Post comments use giscus with this repository's GitHub Discussions, in the
Announcements category. The giscus GitHub App must be installed for this repository.
Repository and category IDs are configured in `_config.yml`; `giscus.json` limits
embedding to the production origin and local previews. Discussions are matched by
post pathname, so keep existing post URLs stable. The first comment or reaction
creates its discussion. Visitors need a GitHub account to participate, and comments
can be moderated on GitHub. Set `comments: false` in a post's front matter to
disable its discussion, or remove `giscus.repo` to disable comments globally.

Sharing metadata is generated by `jekyll-seo-tag`. The default 1200×630 sharing
image is `images/social-card.png`; its HTML/CSS source is `scripts/social-card.html`.
To update the card, render that source at a 1200×630 viewport and save a PNG
screenshot to the image path. Individual posts can override `image` and
`description` in front matter. Preserve original publication dates and use
`last_modified_at` for substantive updates.

The workflow in `.github/workflows/pages.yml` builds pull requests targeting
`master`. Pushes to `master` build and deploy the site; it can also be run manually
from `master`. Builds use the Ruby version in `.tool-versions` and the Bundler
version and dependencies in `Gemfile.lock`.

Before the first deployment, open the repository's **Settings → Pages** and change
**Build and deployment → Source** from **Deploy from a branch** to **GitHub
Actions**. Keep the custom domain set to `codedissolved.com` and HTTPS enforced.
Then merge/push this workflow to `master`, or run it manually there. Feature
branches and pull requests cannot deploy.

The `github-pages` environment must allow deployments from `master`. Deployment
uses GitHub's built-in token; no additional secrets are needed. Inspect the
**Build and deploy site** run in the Actions tab to confirm the deployment.

To roll back, revert the affected commit on `master` and push it to redeploy the
previous source. Keep the GitHub Actions publishing source: the legacy Pages
builder uses Jekyll 3 and cannot use this site's Jekyll 4 dependencies.
